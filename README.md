# odin-library


A lightweight web app to manage a personal book collection, built as part of **The Odin Project** curriculum. This project demonstrates my transition from basic JavaScript to scalable Object-Oriented Programming (OOP).

## Key Technical Growth

* **Memory-Efficient OOP**: Used prototypal inheritance (`Book.prototype`) to share methods instead of duplicating code.
- **Dynamic DOM UI**: Built the entire table view programmatically using JavaScript DOM creation APIs.
- **Robust Data Binding**: Mapped HTML elements to data objects using `crypto.randomUUID()` and `data-id` attributes to prevent deletion bugs.
- **Modern Flexbox Layout**: Designed a responsive 50/50 split-screen view for the form and data.

## Stack & Architecture

- **Tech**: Vanilla JavaScript (ES6), CSS3 (Grid), HTML5.
- `index.html`: Semantic shell for the data grid.
- `styles.css`: Container scaling.
- `script.js`: State management and event orchestration.
